Avife
=====

Digital evolution in Rust

Avife, at least for now, is a faithful re-implementation of the original Avida
Heads hardware, 2-dimensional grid, and 9-logic task environment. Its primary
reason for existing is that I wanted to hands on explore Rust as a language and
for me this was a fun, non-trivial project in which to do so.  As such, it has
been ground up rewritten here in Rust, though really only changing shape to fit
the borrow checker and memory model.

The first skeleton has been good ol' hand written so that I could learn to
understand the language, but that's not a mode I expect to continue. Unleash
the claude!

I have no particular goals for this project other than to have fun. Stay
curious.
